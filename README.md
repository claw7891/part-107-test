# FAA Part 107 Remote Pilot Test Prep

A self-contained study interface with 300 sample multiple-choice questions for the FAA Part 107 Remote Pilot certification exam.

## Features

- 300 questions covering all Part 107 knowledge areas
- Select an answer and verify if it's correct
- Detailed explanations for every question
- Progress tracking with a visual progress bar
- Score summary at the end

## Topics Covered

- **Regulations** (14 CFR Part 107)
- **Airspace** (Classes B, C, D, E, G, special use airspace)
- **Weather** (METARs, TAFs, fronts, fog types, winds)
- **Loading & Performance** (CG, payload, battery management)
- **Operations** (VLOS, RTH, emergency procedures)
- **Crew Resource Management** (ADM, risk assessment)
- **Radio Communications** (phrases, frequencies, emergencies)
- **Airports** (markings, patterns, signage)
- **Physiological Factors** (fatigue, hypoxia, alcohol)
- **Night Operations** (lighting, civil twilight, cold weather)
- **Maintenance & Preflight** (inspections, LiPo safety)
- **Sectional Charts** (symbols, airspace, obstacles)
- **Mapping & Surveying** (photogrammetry, GCPs, LIDAR, NDVI)
- **Drone Technology** (GPS, RTK, sensors, gimbal)
